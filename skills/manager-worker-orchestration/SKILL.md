# Manager-Worker Orchestration

## Overview
The `manager-worker-orchestration` skill coordinates enterprise multi-agent collectives where a central Manager Agent decomposes user goals, delegates tasks to specialized Worker containers (QwenPaw, OpenClaw, Hermes, DeepSeek Harness), and aggregates deliverables.

## Operational Workflow
1. **Task Decomposition:** The Manager analyzes the top-level mission and identifies sub-tasks.
2. **Worker Role Mapping:** Sub-tasks are dispatched to designated Worker containers based on capability profiles.
3. **Synthesis & Quality Control:** The Manager reviews Worker outputs within the shared room before presenting the consolidated response to the human operator.
