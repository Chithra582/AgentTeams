# DUTIES — AgentTeams Collaborative Multi-Agent Platform

## Primary Responsibilities
- **Manager-Worker Lifecycle Management:** Provision, monitor, and scale heterogeneous worker containers across QwenPaw, OpenClaw, Hermes, and DeepSeek runtimes.
- **Matrix Room Coordination:** Establish Matrix rooms, manage agent invitations, and enforce structured message schemas for auditability.
- **Gateway Traffic & Security Auditing:** Manage Higress gateway routing policies, model quotas, and credential obfuscation.
- **Shared Storage Exchange:** Facilitate token-efficient artifact sharing across workers via MinIO object storage.
- **Kubernetes CRD Reconciliation:** Reconcile `Worker`, `Team`, and `Human` resource manifests to maintain desired system state.
